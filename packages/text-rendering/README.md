# Text Rendering

Text rendering example.

The scene demonstrates `TextSprite` nodes rendered as billboarding scene objects
and immediate HUD text rendered by the device text helper.

Key APIs:

- `new TextSprite(scene)`
- `TextSprite.text`
- `TextSprite.font`
- `TextSprite.textColor`
- `device.drawText()`

Run with `?dev=webgl`, `?dev=webgl2`, or `?dev=webgpu` to choose a backend.
